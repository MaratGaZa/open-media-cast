Общий оригинал не копируется и не редактируется из этого проекта. Ссылка исключена из Git, поскольку её абсолютный адрес относится к рабочему месту владельца. Она не входит в переносимый source-репозиторий.

Для другого рабочего места сначала обеспечь наличие общего skill, затем из корня source-репозитория создай ссылку, если путь назначения свободен:

```sh
test -f "$HOME/AI-Skills/evolve-ai-instructions/SKILL.md"
ln -s "$HOME/AI-Skills/evolve-ai-instructions" .agents/skills/evolve-ai-instructions
```

Выполняй вторую команду только при успешной первой. Не используй принудительную замену существующего каталога или ссылки. После создания проверь `readlink` и чтение `SKILL.md`. Наличие корректной ссылки само по себе не доказывает автоматическое обнаружение конкретным агентом; при необходимости передай ему путь явно.

## Когда нужен общий skill

Применяй его к обоснованному улучшению инструкций по результатам наблюдений и оценки. Сначала прочитай `SKILL.md` по разрешённой ссылке и ссылки внутри него, разрешая пути относительно реального каталога skill. Не запускай этот протокол при обычном изменении продукта, исправлении текста или каждой новой сессии.

Протокол общего skill версии 2.0.0 различает draft, candidate и accepted, а также проверки lint, verify и gate. Установка ссылки не означает прохождение этих проверок. Общий skill требует зафиксированных evidence, сравнения baseline/candidate, отдельного held-out case, полного rollback commit и независимого решения при принятии. В исходном репозитории сейчас нет коммитов, поэтому полноценный promotion gate не заявляется пройденным.

Первоначальный набор установлен по прямому поручению владельца; черновики сохранены в капсуле как материал обсуждения. Эта установка не является доказанной эволюцией работающего baseline или статусом accepted по формальному протоколу. Для последующих изменений проверенного набора сохраняй отдельное proposal на одно изменение поведения; не считай разные перепечатки одного примера независимыми evidence. До формального принятия не обозначай draft как accepted.

## Применение расширения

`plan-spec-change`, `review-change`, `debug-media-session`, `handoff-session` добавлены в `.agents/skills/` и таблицу маршрутизации `AGENTS.md` после согласования владельцем. Рабочие версии находятся здесь, а сохранённые в капсуле черновики не следует редактировать как второй источник инструкций.

Контракт и пути продукта остаются в `AGENTS.md`, SPEC, ADR, планах и runbooks. Skills описывают выполнение конкретной работы и ссылаются на эти источники. Отдельные roles, slash commands, копии под каждого провайдера и обязательный publisher сейчас не вводятся.
