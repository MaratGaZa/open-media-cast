## Зависимости и параллельность

Инвентарь и media fixture предшествуют receiver-spikes. AirPlay, DLNA и Cast можно исследовать независимо после подготовки стенда. UI и тесты core могут продвигаться при недоступном одном приёмнике, но его qualification gate остаётся открыт. Будущая Android-версия четвёртая по выпуску; ранняя небольшая проверка FFI/lifecycle предупреждает неподходящую архитектуру, не является началом полномасштабного Android UI.

Календарные сроки не назначены. После D1 оценивать размер задач по фактическим результатам, а не по скорости генерации кода агентом. Один законченный вертикальный сценарий важнее числа сгенерированных файлов.

## Что не входит автоматически

Новые протоколы, iOS, Intel macOS, screen mirroring, cloud relay, сервер домашней медиатеки, магазины приложений и платежи не добавляются без решения. Публичная лицензия, каналы распространения и GitHub repository names ещё не выбраны.
