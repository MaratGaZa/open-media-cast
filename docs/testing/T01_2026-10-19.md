# T01 — HTTP contract tests

2026-10-19. [Issue #1](https://github.com/MaratGaZa/open-media-cast/issues/1).
Статус: локальные проверки выполнены; независимое review/approve и merge ожидаются.

## Scope

Неизменённый исследовательский `tools/protocol-lab/media_server.py` плюс отдельные
регрессионные тесты. Семь тестовых методов проверяют ответы HTTP и остановку
собственного процесса. Каждый метод поднимает отдельный loopback listener на
случайном порту и создаёт 4096 синтетических байт. Телевизоры, LAN и реальные
медиафайлы не используются. Команда и контракт — в [TEST_FIRST](../runbooks/TEST_FIRST.md).

## Результаты

- macOS ARM64, Python 3.13.11, aiohttp 3.14.5.
- `python -m unittest discover -s tools/protocol-lab -p test_media_server.py -v`:
  7 tests, OK; первый полный успешный запуск 1.091 s.
- Первоначальная попытка в sandbox остановилась до тестов: локальный сокет
  запрещён окружением. Это не RED функциональности. После разрешения loopback
  тесты выполнены; ошибка не скрыта через skip.
- Контроль чувствительности: во временной копии заменить
  `web.FileResponse(path,` на `web.Response(body=path.read_bytes(),`.
  Запуск тех же 7 тестов: exit 1, пять failures — четыре варианта Range вместо
  206 получили 200, недостижимый Range вместо 416 получил 200. Errors: 0.
- В другой временной копии заменить `app.router.add_get(route, serve)` на
  `app.router.add_get("/{tail:.*}", serve)`.
  Те же тесты: exit 1, четыре failures — неверный токен/корень/имя/traversal
  получили 200 вместо 404. Errors: 0.
- Сервер в рабочем дереве не модифицировался этими экспериментами.

## Самопроверка и границы

Это авторская самопроверка, не независимый approve. Проверены assertions по
status/Content-Range/Content-Length/байтам, изоляция процессов между тестами,
ограничения ожидания и cleanup при исключениях. Падения мутаций вызваны проверкой
поведения, а не импортом или отсутствием зависимости.

Проверки соответствуют части TEST-HTTP-01/02, E2 лабораторного эталона. Они не
доказывают кодеки, работу Rust, отзыв активной выдачи по session ID, Android,
параллельную раздачу, работу телевизоров или CI. Rust workspace не создан и
ADR-003 не принят этим изменением. GitHub Actions — следующий отдельный шаг T02.
Зависимость aiohttp закреплена напрямую; полная фиксация CI-окружения относится
к T02. Отмена изменения после merge — отдельный revert данного PR.
